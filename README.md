# AirBNB-Home-Listings-Analysis
This project is about analyzing and visualizing the home listings offered by AirBNB in Seattle, USA using Tableau.

## Dataset

The dataset used in this project is available on Kaggle.

- **Source:** [AirBNB Home Listings Dataset](https://www.kaggle.com/datasets/alexanderfreberg/airbnb-listings-2016-dataset)
- **Description:** Contains the home listings in Seattle offered by airBNB, along with listing_id, reviewer_id, customer name and feedback.
